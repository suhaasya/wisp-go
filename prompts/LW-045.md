# Task LW-045: Packaging, install script and self-update
Milestone M4 (Release) · Priority P0 · Estimate 3 d · Step 45 of 48

## Your role
You are a senior engineer (Go, TypeScript and Preact) building Wisp, a local database client for PostgreSQL, MySQL and MariaDB. One Go binary serves a private HTTP server on 127.0.0.1 and the UI runs in the browser (Preact + TypeScript, built with Vite, styled with Tailwind CSS v4). Low memory for the Go process and for the browser tab is a deal breaker. Read AGENTS.md at the repository root before you start; its rules apply to this task.

## Goal
Signed, small release binaries for all platforms, a one-line install script, Homebrew and Scoop, and `wisp --update`.

## Why this matters
A single static binary is the whole product; distribution should be just as simple.

## What to build (do these steps in order)
1. GoReleaser: builds for 5 targets with CGO_ENABLED=0, -trimpath, -ldflags '-s -w'; archives tar.gz/zip; checksums; signatures with cosign or minisign.
2. macOS: optional codesign and notarization of the binary when credentials exist in CI secrets.
3. install.sh / install.ps1: detect OS/arch, download, verify checksum and signature, install to ~/.local/bin or %LOCALAPPDATA%.
4. Homebrew tap and Scoop manifest generated by GoReleaser.
5. `wisp --update`: fetch latest release metadata, download, verify signature with embedded public key, replace the running binary atomically (rename on Windows), print old → new version.
