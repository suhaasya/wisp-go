## Goal
Suggest tables, columns, keywords and functions in context, using metadata Go already caches.

## Why this matters
Autocomplete is the biggest speed win in the editor and must not query the database per keystroke.

## What to build (do these steps in order)
1. Use @codemirror/lang-sql schema completion: provide a schema object built from Go metadata (tables → columns) for the current schema, fetched once per tab and refreshed on SSE 'schema' events.
2. For tables referenced but not yet loaded, request their columns in the background and update the completion source.
3. Alias handling via lang-sql's built-in support; add keyword and function lists per dialect.
4. Completion detail shows type and table in ink-3.

## Files to create or change
- web/src/editor/complete.ts
- internal/api/schema.go (GET .../complete?schema=&tables=)

## UI specification

- Check both light and dark themes against the screenshots.

## Acceptance criteria (every one must pass)

- No database query per keystroke (server log check).
