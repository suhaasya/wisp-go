## Goal
Encrypt database connections with Go crypto/tls supporting all standard modes, custom CAs and client certificates.

## Why this matters
Almost every hosted database requires TLS; Go's standard library covers it without extra dependencies.

## What to build (do these steps in order)
1. Build tls.Config from SSLConfig: disable, prefer (try TLS then plain), require (encrypt, InsecureSkipVerify with a custom VerifyConnection that still records the cert), verify-ca (verify chain, skip hostname via VerifyConnection), verify-full (standard).
2. Roots: system pool (x509.SystemCertPool) or the chosen CA file; client cert/key via tls.LoadX509KeyPair (PEM; PKCS#8, RSA, EC).
3. Postgres: set pgconn.Config.TLSConfig and fallbacks for prefer. MySQL: mysql.RegisterTLSConfig with a unique name per session and tls=<name> in the DSN.
4. ServerInfo returns negotiated version and cipher (from tls.ConnectionState) for the Test line.
5. SSL tab: mode segmented control, CA (system or file via picker), client cert and key via picker; warning banner when a remote host uses Disable.
