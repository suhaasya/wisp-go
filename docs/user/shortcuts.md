# Keyboard shortcuts

Defaults use **Mod** = ⌘ on macOS and Ctrl on Windows/Linux.

| Action | Default |
| --- | --- |
| Command palette | Mod+K |
| Shortcut help | Mod+/ |
| Run query | Mod+Enter |
| New connection | (see in-app **Settings → Shortcuts**) |

Browser-owned shortcuts (close tab, new tab, reload, etc.) are **not** overridden.

## Customisation

**Settings → Shortcuts** lists actions and chords. Conflicts show an alert until resolved.

## Accessibility

Workspace tab lists support arrow-key navigation. See [accessibility.md](../accessibility.md) for focus order and reduced-motion behaviour.
