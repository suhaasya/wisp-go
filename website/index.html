Wisp

A local client for PostgreSQL, MySQL and MariaDB. One Go process on 127.0.0.1; the UI in your browser. No Electron, no cloud account.

Go process budgets

Targets are goals; deal breakers block release (see AGENTS.md).

Metric Target Deal breaker
Binary (embedded UI) ≤ 15 MB 25 MB
Download (compressed) ≤ 7 MB 10 MB
RSS idle, one tab ≤ 20 MB 30 MB
RSS, 1 conn + 500-table schema ≤ 30 MB 45 MB
RSS per extra connection ≤ 2 MB 4 MB
RSS, 1M-row table scrolled ≤ 50 MB 80 MB
Start to page served ≤ 100 ms 300 ms

Install

curl -fsSL https://raw.githubusercontent.com/suhaasya/wisp-go/main/scripts/install.sh | sh
wisp

Windows: PowerShell install script in docs/release.md. Updates: wisp --update.
