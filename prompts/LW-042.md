## Goal
Connect through Unix sockets and Windows named pipes, and offer one-click profiles for detected local databases.

## Why this matters
Local Homebrew, Postgres.app and Linux package installs often listen only on sockets.

## What to build (do these steps in order)
1. PG sockets: host = socket directory in pgx config; known dirs /tmp, /var/run/postgresql, /run/postgresql, Homebrew, Postgres.app.
2. MySQL sockets: unix(/path) in DSN; named pipe on Windows via RegisterDialContext using github.com/Microsoft/go-winio (allowed for Windows builds only) or net dial to \\.\pipe\MySQL.
3. Enable Socket and Named pipe in the form's Connect using control; path via file picker.
4. Detect local databases: check known socket paths and localhost ports 5432/3306/3307 (200 ms timeout each); show suggestions on the Connections screen.
