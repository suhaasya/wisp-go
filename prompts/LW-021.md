## Goal
Own every live database connection: open, keep alive, reconnect, close, and enforce read-only and confirm-every-write before SQL reaches the database.

## Why this matters
All writes from any screen pass through here, so safety rules are enforced once, server-side.

## What to build (do these steps in order)
1. Session: main Conn, lazily opened metadata Conn, transport handles, profile snapshot, state (Connecting, Ready, Busy, Reconnecting, Failed, Closed), last activity.
2. API: POST /sessions {profileId} → {sid, serverInfo}; DELETE /sessions/{sid}; GET /sessions/{sid}/info. Emit SSE 'session' events on state changes.
3. Keep-alive: ping metadata Conn every KeepAliveSec when idle; on error → Reconnecting with backoff 0.5, 1, 2, 4, 8 … max 30 s; Failed after 5 minutes.
4. Write guard: classify the first statement keyword (after comments): SELECT, SHOW, EXPLAIN (without ANALYZE), WITH…SELECT, DESCRIBE, VALUES = read; anything else = write. ReadOnly → reject writes with 403-style error; also set DB read-only (PG: SET SESSION CHARACTERISTICS AS TRANSACTION READ ONLY; MySQL: SET SESSION TRANSACTION READ ONLY). SafeMode → return needsConfirmation with the SQL unless the request carries confirm: true.
5. Close sessions on shutdown and when no tab references them for 30 minutes.
