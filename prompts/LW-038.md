## Goal
Export selection, page, result or whole table to CSV, JSON, SQL INSERT or Markdown, streamed from the database through Go to a browser download.

## Why this matters
HTTP streaming makes huge exports cheap: rows go from the database cursor to the network with a small buffer, never held in memory.

## What to build (do these steps in order)
1. Dialog: source, format and options, destination (browser download or local path via file picker for very large exports).
2. GET .../export?... responds with Content-Disposition attachment and streams rows written through bufio.Writer (64 KB) and http.Flusher every window.
3. Local-path mode writes to disk in Go and reports progress over SSE with cancel.
4. Small selections (< 10k rows) can be copied to the clipboard through the same writers.
