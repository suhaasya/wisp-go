## Goal
Import CSV, JSON lines or SQL files chosen from a local path, with preview, column mapping, progress and error report.

## Why this matters
Reading the file in Go from its path avoids uploading through the browser, so the tab never holds file data.

## What to build (do these steps in order)
1. Step 1: choose a file with the Go file picker; Go detects encoding and delimiter and returns the first 100 rows.
2. Step 2: map to an existing table or create a new one with inferred types.
3. Step 3: options (NULL markers, batch size, transaction mode, stop on error).
4. Fast paths: pgx CopyFrom for PostgreSQL; LOAD DATA LOCAL INFILE (with a registered reader handler) for MySQL when allowed, else multi-row INSERT batches.
5. SQL files: stream statements through the splitter and execute sequentially with byte-based progress.
6. Error report with line numbers (max 1,000) downloadable as CSV.
