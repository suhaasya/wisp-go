## Goal
Change table structure through forms and review the exact ALTER statements before they run.

## Why this matters
Structure changes are risky and dialect-specific; showing generated SQL first keeps users in control.

## What to build (do these steps in order)
1. Structure change set in Go: add/drop/rename column, change type, nullability, default, comment; add/drop index and FK.
2. Inline editing in Columns and Indexes boxes with the same colour states as data edits; 'Pending changes' box shows live SQL.
3. PG: ALTER TABLE … ALTER COLUMN TYPE … USING, SET/DROP NOT NULL, SET/DROP DEFAULT, COMMENT ON COLUMN, CREATE INDEX (CONCURRENTLY option, outside transaction); run in one transaction otherwise.
4. MySQL: MODIFY COLUMN with full definition regenerated from metadata, RENAME COLUMN (8.0+) or CHANGE (5.7), ADD/DROP INDEX; warn that DDL auto-commits.
5. Warnings: type narrowing, SET NOT NULL with existing NULLs (quick check), large table rewrites.
6. Apply through the Review SQL dialog; invalidate metadata and refresh after success.
