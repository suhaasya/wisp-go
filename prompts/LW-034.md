## Goal
Searchable query history and saved snippets, plus crash-safe restore of open tabs, SQL text and staged edits.

## Why this matters
Because state lives in Go, restore is mostly about persisting it to disk safely.

## What to build (do these steps in order)
1. History: append-only JSONL per profile (ts, sql, ms, rows, status); rotate at 5 MB keeping newest half; per-profile option to disable; parameter values never stored.
2. GET /history?profile=&q= streams matches from the end of the file (max 200).
3. Snippets in snippets.json (name, tags, sql); available in the palette and autocomplete.
4. Journal: workspace state and change sets written debounced (1 s) to data/journal/<profile>.json atomically; restored at session open; cleared on clean close; cap 2 MB.
5. Drawer UI 360 px over results: search, list grouped by day, click inserts, double-click runs.
