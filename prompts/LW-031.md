## Goal
A capable SQL editor loaded only when a query tab opens, destroyed when it closes, with highlighting in theme colours.

## Why this matters
Writing an editor from scratch is not worth it on the web; CodeMirror 6 is modular and small when only the needed packages are bundled.

## What to build (do these steps in order)
1. Dynamic import('./editor/index.ts') from QueryTab.tsx so Vite emits a separate chunk (budget js_editor_kb_gz); the Preact component holds a ref and creates the EditorView in useEffect.
2. Extensions: lineNumbers, highlightActiveLine, history, bracketMatching, closeBrackets, search (Ctrl/⌘+F inside editor), sql({dialect: PostgreSQL or MySQL}).
3. Theme built from CSS variables (var(--color-syn-keyword) etc.) so light/dark switch without rebuild.
4. On unmount: the effect cleanup calls view.destroy() and drops references.
5. Go statement splitter: respects quotes, backticks, comments, PG dollar quoting and MySQL DELIMITER; returns byte ranges. The page sends the cursor offset; Go picks the current statement.
