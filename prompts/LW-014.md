## Goal
Connect to MySQL 5.7/8.x and MariaDB 10.4+ over TCP, stream results into windows, and cancel statements.

## Why this matters
go-sql-driver/mysql is the de facto standard. It goes through database/sql, so use a dedicated *sql.Conn per session and raw column scanning.

## What to build (do these steps in order)
1. Open sql.DB with SetMaxOpenConns(1) and take a dedicated *sql.Conn for the session; DSN with parseTime=false (dates as text), interpolateParams=false, timeout settings.
2. Auth plugins: caching_sha2_password (needs TLS or allowPublicKeyRetrieval for RSA exchange: expose as option), mysql_native_password.
3. Query: scan each row into []sql.RawBytes and copy into the window arena per column type using ColumnTypes().
4. Type mapping: tinyint(1) → bool (setting), integers, decimal → text, float/double, char/varchar/text, blob/binary → bytes, json → text, date/datetime/timestamp/time → text, enum/set → text, bit → hex text.
5. Cancel: on context cancel run KILL QUERY <id> on a short-lived second connection (connection id from SELECT CONNECTION_ID()).
6. Detect MariaDB from version string; set dialect name accordingly.
