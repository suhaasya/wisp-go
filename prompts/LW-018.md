## Goal
Paste a connection URL anywhere on the Connections screen, or into the form, and get a correctly filled form.

## Why this matters
Hosted providers hand users a URL; turning it into a connection in one paste is a key moment.

## What to build (do these steps in order)
1. Parse postgres:// and postgresql:// (sslmode, sslrootcert, options, application_name, connect_timeout), libpq key=value strings, mysql:// and mariadb:// (ssl-mode, tls), and .env lines (DATABASE_URL=..., quotes, export prefix).
2. Percent-decode user and password; IPv6 in brackets; first host if several (return a warning).
3. Provider detection by host suffix (supabase.co, neon.tech, rds.amazonaws.com, psdb.cloud, cloudsql/googleapis.com, azure.com) → provider tag and TLS default.
4. Unknown params kept in options.extra.
5. Page: document paste listener on Connections screen when no input is focused → POST parse-url → open form pre-filled (password kept only in the form state until saved).
