# Task LW-013: PostgreSQL driver (pgx)

## Goal
Connect to PostgreSQL 12–17 over TCP with pgx, stream results into windows, and cancel running statements.

## Why this matters
pgx gives direct protocol access, cancellation and fast decoding without database/sql overhead.

## What to build (do these steps in order)
1. Use pgx.Connect (not pgxpool); ConnectParams → pgconn.Config with application_name=wisp, connect_timeout, statement_timeout via RuntimeParams.
2. Auth: SCRAM-SHA-256, MD5, trust; .pgpass via pgpassfile when no password.
3. Query: conn.Query with QueryExecModeSimpleProtocol only where needed; read rows with rows.RawValues() and decode per column type into the Window vectors (avoid Values()).
4. Type mapping: int2/4/8, float4/8, numeric → text, text/varchar/bpchar/name, bytea → bytes (first 4 KB), bool, json/jsonb → text, uuid, date/time/timestamp/timestamptz → ISO text, arrays and unknown → text via the text format.
5. Cancellation: context cancel triggers pgconn cancel request; verify pg_sleep(30) stops within 500 ms.
6. ServerInfo: version(), current_database(), current_user.
